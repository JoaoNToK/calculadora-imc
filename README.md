# 🧮 Calculadora de IMC

Uma calculadora de **IMC (Índice de Massa Corporal)** desenvolvida com **HTML semântico**, **CSS moderno** e **JavaScript puro**.  
O objetivo do projeto é demonstrar conceitos básicos de desenvolvimento web, manipulação do DOM e boas práticas de estruturação de código.
